# 📱 مساعد سحاب الذكي (SAHAB AI Assistant)

مساعد ذكي متخصص في استشارات شاشات الجوالات، البطاريات، وقطع الغيار الأصلية والبديلة، مدعوم بنموذج **Google Gemini 3.5 Flash**.

---

## 🌟 المميزات
- **إجابات دقيقة واحترافية:** توضيح الفروقات التقنية بين أنواع الشاشات (OLED، Incell، TFT، الأصلية، المعاد تصنيعها).
- **حماية المفاتيح البرمجية (Serverless API):** مزود بدالة خادم سحابية `/api/chat` جاهزة لـ Vercel لحماية مفتاح API.
- **يعمل محلياً وسحابياً:** متوافق مع النشر المباشر على Vercel أو العمل محلياً.
- **توجيه مباشر للطلب:** ربط فوري بالواتس والاتصال بمركز سحاب (778267604).

---

## 🚀 النشر على Vercel
1. ارفع المشروع إلى حسابك في **GitHub**.
2. توجّه إلى منصة [Vercel](https://vercel.com).
3. اختر **Add New... -> Project** ثم حدد هذا المستودع.
4. في قسم **Environment Variables**، يمكنك إضافة:
   - الاسم: `GEMINI_API_KEY`
   - القيمة: مفتاحك الخاص من [Google AI Studio](https://aistudio.google.com).
5. اضغط **Deploy**.
